# Клиника Кожа Dashboard

Компактный статический дашборд рекламных показателей по месяцам.

## Что внутри

- переключение между Яндекс.Директ, 2ГИС и Яндекс.Бизнес;
- KPI по расходу, лидам, CPA и другим доступным метрикам;
- графики для сравнения 2+ месяцев;
- при выборе одного месяца графики скрываются;
- данные сгруппированы по месяцам и раскрываются отдельно;
- мобильная версия с компактными KPI и карточным видом таблиц.

## GitHub Pages
